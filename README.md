A program that draws one open passport spread for the Republic of Talvaria,
a country that isn't there: a data page with a drawn portrait, personal
details and a machine-readable zone, facing a visas page with one coherent
travel history — Kessan in and out in June 2023, an Ostara visa, a Port of
Lys entry in 2025 — and the salt levy stamp and juniper-sprig condition that
give the place away. Pure Python stdlib, no network, deterministic.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×700, under 1 MiB).
